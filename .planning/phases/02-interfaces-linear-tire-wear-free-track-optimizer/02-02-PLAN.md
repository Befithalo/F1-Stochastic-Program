## Phase Goal

**As a** quant-minded F1 strategy analyst, **I want to** see how many seconds per lap each tyre compound loses, after removing the effect of the car getting lighter, **so that** I can trust the tyre model that every later pit recommendation is priced with.

**ROADMAP goal (verbatim):** User can get the fastest free-track 1- or 2-stop plan for a race from fitted, fuel-corrected tire wear, behind interfaces later milestones can plug into.

This plan is the wear slice (success criterion 4). After Task 2 a library user can fit a race; after Task 3 `uv run f1si wear bahrain-2023` prints the numbers.

Output: `src/f1si/laps.py`, `src/f1si/pace/linear.py`, the `wear` CLI command, long synthetic fixtures, recovery and identification tests, DEC-063 to DEC-066.

fit_linear_pace(snapshot: RaceSnapshot) -> LinearPaceFit (never raises for shortage of data). Steps: (1) take snapshot.laps; empty gives an unidentified fit with message "no laps visible yet". (2) Classify each lap, counting the first matching reason in this order: "no lap time" (lap_time_s NA), "lap 1", "pit in", "pit out", "safety car/VSC/red" via f1si.laps.fade_reason(lap, pit_in, pit_out, track_status) with is_pit_in_lap/is_pit_out_lap filled False, "no compound or tyre age", "wet compound" (compound not in DRY_COMPOUNDS after upper-casing; compound normalisation as in prepare_stint_plot_data). (3) Build the design matrix from scratch on EVERY pass: columns = one dummy per driver with at least MIN_DRIVER_LAPS laps, one fuel column (lap_number - 1), and one column per compound kept, equal to tyre_life where the lap's compound is that compound else 0. A compound is kept only if it has >= MIN_CLEAN_LAPS_PER_COMPOUND clean laps and >= MIN_STINTS_PER_COMPOUND distinct (driver, stint) pairs, otherwise it is listed in not_enough_data and its laps leave the regression; re-evaluate after every trim. (4) Solve with np.linalg.lstsq; compute the SVD rank; if rank < ncols or cond(X) > COND_LIMIT or n - p < MIN_RESID_DF, find the unidentified parameter names from the null-space rows (columns whose absolute loading exceeds 1e-8) and return a fit with fuel and wear numbers None, unidentified filled by name ("fuel effect", "wear HARD", ...), and a plain-language message; do NOT use the minimum-norm lstsq answer. (6) Final: classical s2 = rss/(n-p), SE = sqrt(diag(s2 * inv(X'X))), interval estimate +/- CI_Z * SE, sigma_s = sqrt(s2).
