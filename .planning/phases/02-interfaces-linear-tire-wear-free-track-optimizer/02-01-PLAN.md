## Phase Goal

**As a** quant-minded F1 strategy analyst building this platform, **I want to** plug models, policies and simulators into typed interfaces that a shared test suite polices, **so that** later phases (Monte Carlo, Kalman, Longstaff-Schwartz, Bayesian) can be swapped in without breaking the rest.

**ROADMAP goal (verbatim):** User can get the fastest free-track 1- or 2-stop plan for a race from fitted, fuel-corrected tire wear, behind interfaces later milestones can plug into.

This plan delivers the contract slice (INT-01, INT-02, INT-03 type and JSON part). After it, a developer can write a stub, run the suite and see it pass or fail. The builder that fills a `RaceState` from a race arrives in plan 02-03.

Define the three Protocols, the shared `RaceState`, and the conformance harness that proves a conforming implementation passes and each kind of bad stub fails.

PaceModel.predict(self, *, driver: NDArray[np.int64], compound: NDArray[np.str_], tire_age: NDArray[np.int64], lap: NDArray[np.int64]) -> tuple[NDArray[np.float64], NDArray[np.float64]]
