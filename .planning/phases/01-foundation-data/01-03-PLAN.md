## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Source adapter output → cache | Source tables are untrusted until validated |
| CLI arguments → loader | `--seasons`, `--only`, `--data-dir` come from the user |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-11 | Tampering | Source tables entering the cache | mitigate | `schema.validate_race` (required tables/columns, null/duplicate keys, status code set, referential checks) runs before any write; failures are recorded, never written |
| T-01-12 | Tampering (evaluation integrity) | lap_cutoffs | mitigate | Cutoffs precomputed at load with reverse cumulative minimum so the door never computes min(lap_end) over future rows; property test on synthetic data checks leader N / others N-1 |
| T-01-13 | Denial of service | One bad race aborting a 20-minute load | mitigate | Per-race failure collection, resumable skip of complete races, bounded retries with injected sleep |
| T-01-14 | Tampering | Mixing synthetic and real races in one cache (fake races would enter real history) | mitigate | MixedSourceError raised before any fetch when the cache holds another source |
| T-01-15 | Tampering | `--seasons` / `--only` input | mitigate | Seasons validated through `era_for_season`; `only` values only compared against schedule race_ids/slugs, never interpolated into SQL or paths |
</threat_model>
