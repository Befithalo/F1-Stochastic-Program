**ROADMAP goal (verbatim):** User can load 2023-2025 races into a local cache, see Bahrain 2023 lap times by stint, and trust that no code can read future data.

**This plan's slice:** after this plan any code can ask "what did we know at lap N of race R?" through one door and get exactly that, final results sit behind a separate door, 2026 is locked, and CI proves with scrambled futures and planted leaks that nothing reads ahead. This is the "trust" part of the phase goal and roadmap success criterion 4.
