## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| OpenF1 / Jolpica JSON → normalized tables | Untrusted third-party data enters the cache |
| f1si → free public APIs | Our traffic must respect limits and terms |
| Local real-data cache → public repo | Raw data must never be committed |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-32 | Tampering | OpenF1 row parsing | mitigate | Required-key checks, strict timestamp/number parsing (errors raise SourceError), completeness checks, then schema.validate_race in the loader before any write |
| T-01-33 | Denial of service | OpenF1 rate limit / ToS | mitigate | RateLimitedClient min_interval 2.1 s (≤ 30/min), cache-first re-runs, bounded 429 retries (DEC-017) |
| T-01-34 | Information disclosure / licensing | Raw OpenF1 data republished | mitigate | data/ gitignored and verified untracked (`git ls-files data` empty); no artifacts; credits and non-commercial terms in README and the module docstring |
| T-01-35 | Tampering | Wrong race identity (rounds renumbered, event ≠ circuit) | mitigate | Round from Jolpica schedule matched by date; circuit from circuitId; unmatched sessions skipped with a message (DEC-016) |
