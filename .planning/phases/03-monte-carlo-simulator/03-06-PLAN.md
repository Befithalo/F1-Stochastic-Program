## Phase Goal

**As a** quant-minded F1 strategy analyst, **I want to** run one command for a race, driver and lap and see that driver's finishing-position distribution with the safety-car assumption stated, **so that** I can judge the simulator's output and where its inputs came from.

**ROADMAP goal for Phase 3 (verbatim):** User can simulate 50,000 continuations of a race from any `RaceState` in under 10 seconds with a reliable, low-variance result.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| command-line arguments to program | slug, driver, lap, n, seed are untrusted text |
| program to filesystem | the PNG is written under the reports directory |
| cache to simulator | all data reaches the model only through the as-of door |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-16 | Tampering | path traversal through slug/driver in the PNG file name | mitigate | `sim_file_name` validates slug `^[a-z0-9-]+$`, driver `^[A-Z]{3}$`, int lap >= 0 and builds `sim-...png` under the reports dir; unit tests with `../x` |
| T-03-17 | Denial of service | huge `--n` exhausting memory | mitigate | `--n` bounded to [2, 1,000,000] with a friendly refusal before any simulation; test |
| T-03-18 | Information disclosure | `--lap N` using data after lap N, or 2026 races | mitigate | snapshot and history both taken at `AsOf(race_id, N)`; `OutOfSampleLockedError` refused; SC rate from `History` of earlier races only; existing import-scan test and scramble consumer |
| T-03-19 | Tampering | invalid seed/driver text reaching internals | mitigate | `make_rng` validation, regex and state membership checks produce one-line messages, never tracebacks |
</threat_model>
