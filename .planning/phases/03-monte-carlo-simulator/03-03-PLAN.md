kernel.py: module docstring stating the lap-time model and all rules (numbered): state arrays are lap-major `(n_races, n_cars)` with columns in `RaceState.cars` order (car index = column; draws are indexed by car, never by position, for CRN); `order[r, p]` is the car at running position p (0 = leader); `clock[r, c]` cumulative time of car c when it last crossed the line. One call advances every race by one lap, looping `for r in range(n)` then positions, no `parallel=True`, `fastmath=False`, `@njit(cache=True)`, math only through `math` functions. Expose `pass_probability(delta, threshold_s, scale_s)` as a plain `@njit` function returning `1 / (1 + exp((threshold_s - delta) / scale_s))` (also callable from Python for the D-08 test).

`lap_step(...)` takes (grouping, exact order is the executor's to fix and document in the docstring): the absolute lap number; per-lap table slices `mean_tab[c, comp, age]` and `sd_tab[c, comp, age]` for that lap (age index = laps on the tyres before this lap, +1 applied inside); draws for that lap `u_sc (n,)`, `z_off (n, C)`, `z_wear (n, K)`, `eps (n, C)`, `pu (n, C)`; parameter spreads `off_sd (C,)` and `wear_sd (K,)`; plan arrays `stop_lap (C, S)` (sentinel large value when unused), `next_comp (C, S)`, `opportunistic (C,)` bool; scalars `pit_loss_green`, `pit_loss_sc`, `sc_rate`, `sc_duration`, and the constants `min_gap_s, threshold_s, scale_s, pass_cost_s, sc_slowdown, restart_spacing_s, sc_window, min_stint`; mutable state `order, clock, age, comp, stops_done, sc_left, sc_fresh (n,) bool` (True on the first simulated lap of a race whose safety car was already active at the cutoff, so that lap counts as the SC start for opportunistic stops; the kernel clears it after use) and outputs `pit_paid (n, C)`, `stop_taken (n, C, S)` (lap of each stop, -1 padded), `sc_mask (n,)` for this lap (the caller stores it into the race x lap mask), optional clock record handled by the caller from `clock` after the call. Free time of car c: `mean_tab + z_off*off_sd[c] + z_wear[comp]*wear_sd[comp]*(age+1) + eps*sd_tab` (parameter-draw form from DEC-077: the table already holds the fitted rate).

Per race and lap, in this order: (1) SC start: if `sc_left == 0` and `u_sc[r] < sc_rate` then `sc_left = sc_duration` (the whole lap runs under SC; the lap the SC starts on counts as its first SC lap); under SC the lap mask is True. (2) Free times T per car. (3) Pit decisions: planned stop when `lap == stop_lap[c, stops_done[c]]`; on the lap an SC starts (or `sc_fresh[r]` is True), an opportunistic car whose next planned stop lies within `[lap, lap + sc_window]` and whose following stop (if any) is at least `min_stint` laps later takes it now (the stop is consumed, `stops_done += 1`, the remaining plan is untouched); pit loss added to the arrival is `pit_loss_sc` on an SC lap else `pit_loss_green`; the in-lap uses the old tyre; after the lap age resets to 0 and the compound becomes `next_comp[c, k]`; otherwise age += 1. (4) Arrival `arr[c] = clock[c] + T_eff + pit_loss`, where under SC `T_eff = sc_slowdown * T[leader]` for every car. (5) Green lap, processed front to back over positions p = 1..C-1 with the car c = order[p] and the car ahead a: if `arr[c] < arr[a] + min_gap_s`: if a pitted this lap and c did not, c moves ahead deterministically (bubble up past every such car, no probability, no pass cost); otherwise attempt a pass with `delta = T[a] - T[c]` and success iff `pu[r, c] < pass_probability(delta, threshold_s, scale_s)` (one uniform per car per lap; a car gains at most one position per lap by pass): on success swap positions, `arr[c] += pass_cost_s`, `arr[a] = max(arr[a], arr[c] + min_gap_s)`; on failure `arr[c] = arr[a] + min_gap_s`. (6) SC lap: no passing; stable insertion sort of positions by arrival (only pit stops reorder); if `sc_left == 1` this is the restart lap: after the sort set `arr[order[p]] = arr[order[0]] + restart_spacing_s * p`. (7) Write `clock = arr`, decrement `sc_left` if positive. No lapping, no retirements (D-09). All draws are consumed regardless of what happens (CRN).
