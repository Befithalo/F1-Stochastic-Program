## Phase Goal

**As a** quant-minded F1 strategy analyst, **I want to** see each car's hidden tyre-wear rate estimated lap by lap with an honest uncertainty band, **so that** the simulator and later strategy code can use a calibrated, as-of wear estimate instead of one field-wide number.

**ROADMAP Phase 4 goal:** a Kalman filter estimates each car's hidden tyre-wear rate lap by lap from noisy lap times, with a band that narrows, using only data known at each lap (PAC-03, PAC-04).

<objective>
Capture the Phase 3 reference before anything touches the simulator, then build the pure-array Kalman core (`WearFilter`) with its closed-form oracle and the unit tests for the maths, incremental/batch equality, narrowing, `q > 0`, skipping and the outlier gate.

Purpose: the filter maths is the foundation of PAC-03; the reference capture protects the "fit cars stay byte-identical" constraint for plan 04-03.
Output: `src/f1si/pace/kalman.py` (array core), four unit test files, the reference fixture and its test, a Phase 4 explainer skeleton, DEC-088 to DEC-090.
</objective>
